PRIYO APP — CONSOLIDATED MASTER V-61

This package is the consolidated development master based on the approved V-60 project and the latest PRIYO APP Home Dashboard decisions.

FINAL HOME RULES
- Two promotional banners at the top.
- Welcome banner and Breaking News.
- “লাইভ এখন চলছে” with exactly four compact Live cards and a full “সব দেখুন” target.
- Action row: LIVE | GO LIVE | Priyo Feed.
- Priyo Feed uses a colorful/gradient “P”.
- Online Shopping is the main highlighted shopping tile.
- Gallery contains Photo, Reel, Video and Music.
- External Movie and Live TV are separate tiles.
- Social Media, Earn & Reward, Share, More Apps follow the approved order.
- Chat is not a Home tile; it is available inside More Apps and from the side menu.
- More Apps remains the final tile.
- Right-side ⋮ menu contains Language, Chat, Notifications, Privacy & Security, Settings, Help & Support, About PRIYO APP and Log Out; no Profile header/card is shown.
- Language is one menu item; Bengali/English choices appear only after opening Language.
- Profile remains in Bottom Navigation.
- Home security/privacy strip is removed.
- Mobile and Desktop use the same design identity with responsive sizing and spacing.

QUALITY / SAFETY NOTES
- Admin UI is kept out of normal user navigation and is role-gated in the prototype.
- No APK build is claimed because Android SDK/Gradle is unavailable in this environment.
- This ZIP is the source master for the next GitHub upload/build step.
- Previous recovery/source backups remain under the recovery/ directory.
